# Archive provenance

Raw generation, detector, and oracle-score records are retained from the local
experiments. Their model/data revisions, settings, seeds, source fingerprints,
and recorded environments are preserved in the run manifests.

The public Git history groups the existing implementation and results by
component. Execution commit identifiers in the archives refer to the local
pre-publication history; they are not release-history commit IDs. Per-file source
hashes record the implementation at execution time. Current analysis code is
provided and checked against the saved numerical results.

Publication edits revise narrative documentation for a standalone report and
normalize qualitative reviewer descriptions to model-assisted inspection. Review
labels and substantive notes are retained. Numerical source records are unchanged.
Derived comparison metadata and artifact hashes are rebuilt for the published
files. Qualitative screening is not an independent human evaluation or a validated
semantic-quality metric.

Per-archive `artifact_hashes.json` files cover the delivered artifacts. Replay
commands rebuild numerical reports without loading models. Interpretation files
are editorial reporting; they are not generated by the numerical pipeline.

The ten-prompt pilot is included in the main 100-prompt sample. The two rewriting
pilots use the same 15 source completions from five prompt groups. These archives
must not be treated as independent additional datasets.
